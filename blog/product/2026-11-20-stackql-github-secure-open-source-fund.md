StackQL took part in Session 5 of the [GitHub Secure Open Source Fund](https://github.com/open-source/github-secure-open-source-fund) and is listed among the program's alumni in GitHub's recent post [Maintainers don't need more AI bug reports. They need fixes](https://github.blog/open-source/maintainers/maintainers-dont-need-more-ai-bug-reports-they-need-fixes/) alongside other notable alumni of the program including [__OpenClaw__](https://github.com/openclaw/openclaw), [__LangChain__](https://github.com/langchain-ai/langchain), [__ONNX__](https://github.com/onnx/onnx), [__Ollama__](https://github.com/ollama/ollama), [__FastMCP__](https://github.com/PrefectHQ/fastmcp) and more.

## About the GitHub Secure Open Source Fund

The fund is run by GitHub and powered by GitHub Sponsors. It supports open source projects that underpin the software supply chain and the AI stack. Each project in a session receives security training and guidance from the security experts at GitHub.  

Over 200 projects have been through the program so far, with more than 300 maintainers fixing more than 4,000 vulnerabilities in software downloaded more than 20 billion times a month.  

The full list of alumni projects is in [GitHub's post](https://github.blog/open-source/maintainers/maintainers-dont-need-more-ai-bug-reports-they-need-fixes/).  

Thanks to GitHub, GitHub Sponsors and the program team for supporting StackQL 🚀.
