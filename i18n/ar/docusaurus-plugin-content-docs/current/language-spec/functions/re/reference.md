## بناء الجملة المدعوم {#supported-syntax}

يدعم StackQL بناء جملة التعبيرات النمطية التالي:    

| التعبير | الوصف |
|------------|-------------|
| `X*` | صفر أو أكثر من تكرارات `X` |
| `X+` | تكرار واحد أو أكثر لـ `X` | 
| `X?` | صفر أو تكرار واحد لـ `X` |
| `X{n}` | عدد `n` بالضبط من تكرارات `X` |
| `X{n,}` | عدد `n` أو أكثر من تكرارات `X` |
| `X{n,m}` | عدد يتراوح بين `n` و`m` من تكرارات `X` |
| `(X)` | مطابقة `X` |
| `X`&vert;`Y` | `X` أو `Y` |
| `^X` | `X` في بداية السلسلة النصية |
| `X$` | `X` في نهاية السلسلة النصية |
| `.` | مطابقة أي حرف واحد، بما في ذلك حرف السطر الجديد |
| `\c` | الحرف `c` حيث `c` أحد الأحرف `\{}()[]`&vert;`*+?.` |
| `\c` | تسلسلات الإلغاء في لغة C لـ `c` ضمن `afnrtv`. مثال: `\t` أو `\n` |
| `[abc]` | أي حرف واحد من المجموعة `abc` |
| `[^abc]` | أي حرف واحد ليس في المجموعة `abc` |
| `[a-z]` | أي حرف واحد ضمن النطاق `a-z` |
| `[^a-z]` | أي حرف واحد ليس ضمن النطاق `a-z` |
| `\d`, `\w`, `\s` | رقم، وحرف كلمة (`[0-9A-Za-z_]`)، وحرف مسافة بيضاء |
| `\D`, `\W`, `\S` | أي حرف ليس رقمًا، وأي حرف ليس حرف كلمة، وأي حرف ليس حرف مسافة بيضاء |
| `\b` | حد كلمة |  

&nbsp;  
&nbsp;  
تستخدم الأنماط بناء جملة RE2، كما تنفذه الحزمة `regexp` في Go.  المراجع الخلفية (`\1`) وتأكيدات البحث للأمام والخلف (lookaround) غير مدعومة: يتم رفض النمط الذي يستخدمها ويعاد خطأ.

تبدأ الشرطة المائلة العكسية في القيمة الحرفية النصية في StackQL تسلسل إلغاء (`'\n'` هو حرف سطر جديد)، لذا تكتب الشرطة المائلة العكسية التي تنتمي إلى التعبير النمطي مرتين: يطابق النمط `'\\d+'` رقمًا واحدًا أو أكثر، ويطابق النمط `'[0-9]+\\.[0-9]+'` نقطة حرفية بين الأرقام.

للاطلاع على بناء الجملة الكامل، راجع [بناء جملة RE2](https://github.com/google/re2/wiki/Syntax).
