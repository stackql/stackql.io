# Справочник по провайдерам

Этот раздел генерируется автоматически из спецификаций провайдеров StackQL. Каждая страница описывает один ресурс: его назначение, требования к аутентификации, поддерживаемые методы (SELECT/INSERT/UPDATE/DELETE), рабочий пример на SQL и связанные ресурсы.

Генерация пока не подключена - это заполнитель для генератора, описанного в плане материалов AEO.
