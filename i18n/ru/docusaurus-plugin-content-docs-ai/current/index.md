# Справочник StackQL для ИИ

Этот раздел - параллельный набор материалов для ИИ-агентов, систем ответов на базе ИИ и поисковых роботов LLM. Страницы здесь написаны так, чтобы четко отвечать на конкретные вопросы, с детерминированными примерами и явной схемой. Люди тоже могут их читать, но сайт для людей доступен через навигацию верхнего уровня.
