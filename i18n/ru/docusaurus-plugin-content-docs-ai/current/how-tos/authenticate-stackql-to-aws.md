# Как настроить аутентификацию StackQL в AWS

StackQL проходит аутентификацию в AWS с помощью стандартных переменных среды для учетных данных AWS. Задайте их перед запуском оболочки StackQL, команды `exec`, сервера или MCP-сервера; файл конфигурации не требуется.

## Шаги {#steps}

1. Создайте или выберите субъект IAM (пользователя или роль) с разрешениями, которые нужны вашим запросам. Для запросов только на чтение достаточно управляемой политики `ReadOnlyAccess` или более узкого эквивалента.

2. Экспортируйте учетные данные как переменные среды:

```bash
export AWS_ACCESS_KEY_ID=YOURACCESSKEYID
export AWS_SECRET_ACCESS_KEY=YOURSECRETACCESSKEY
```

Для временных учетных данных (роль, принятая через `sts assume-role`, или сеанс AWS CloudShell, который задает эти переменные автоматически) также экспортируется токен сеанса:

```bash
export AWS_SESSION_TOKEN=YOURSESSIONTOKEN
```

3. Загрузите провайдер AWS (только при первом использовании):

```sql
REGISTRY PULL aws;
```

4. Проверьте аутентификацию с помощью запроса:

```sql
SELECT instance_id, instance_type
FROM aws.ec2.instances
WHERE region = 'us-east-1';
```

Успешно полученный результирующий набор подтверждает аутентификацию. Обратите внимание, что запросам к AWS требуется предикат `region` в предложении `WHERE` - это параметр маршрутизации, а не настройка учетных данных.

## Где действуют переменные {#where-the-variables-apply}

Одни и те же переменные среды работают во всех режимах выполнения StackQL:

- **Интерактивная оболочка**: `stackql shell`
- **Пакетный режим**: `stackql exec "..."`
- **Режим сервера**: `stackql srv` (сетевой протокол PostgreSQL)
- **MCP-сервер**: `stackql mcp` или через блок `env` в конфигурации MCP-клиента, например `claude_desktop_config.json`

В системах CI загружайте переменные из хранилища секретов платформы, а не прописывайте их в коде. Операции с метаданными (`SHOW`, `DESCRIBE`, `REGISTRY`) работают без учетных данных; сеанс с пройденной аутентификацией нужен только для операций с данными (`SELECT`, `INSERT`, `UPDATE`, `DELETE`, `EXEC`).
