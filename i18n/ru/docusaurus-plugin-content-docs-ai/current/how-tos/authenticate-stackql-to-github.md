# Как настроить аутентификацию StackQL в GitHub

StackQL выполняет аутентификацию в GitHub с помощью базовой аутентификации: вашего имени пользователя GitHub и персонального токена доступа (PAT), которые передаются в переменных `STACKQL_GITHUB_USERNAME` и `STACKQL_GITHUB_PASSWORD`. Общедоступные данные доступны для запросов без каких-либо учетных данных в пределах ограничения частоты, которое GitHub устанавливает для запросов без аутентификации.

## Шаги {#steps}

1. Создайте персональный токен доступа в GitHub (Settings -> Developer settings). Предоставьте только те области, которые нужны вашим запросам: без областей для общедоступных данных с более высоким ограничением частоты запросов, `repo` для закрытых репозиториев.

2. Экспортируйте учетные данные:

```bash
export STACKQL_GITHUB_USERNAME=yourghuser
export STACKQL_GITHUB_PASSWORD=ghp_yourgithubpersonalaccesstoken
```

3. Загрузите провайдер GitHub (только при первом использовании):

```sql
REGISTRY PULL github;
```

4. Выполните проверочный запрос:

```sql
SELECT name, description, language, stargazers_count
FROM github.repos.repos
WHERE org = 'stackql';
```

Предикат `org` выбирает метод доступа `list_for_org`; предложение `WHERE username = '...'` вместо него выбирает `list_for_user`. Инструкция `SHOW METHODS IN github.repos.repos` выводит все методы и их обязательные параметры, включая методы изменения данных (`create_in_org`, `update`, `delete`).

## Доступ без аутентификации {#unauthenticated-access}

Приведенный выше запрос работает без учетных данных, потому что организация `stackql` общедоступна - это удобно для ознакомления и для агентов, которые изучают модель запросов до выдачи учетных данных. Ограничение частоты запросов без аутентификации в GitHub низкое (60 запросов в час с одного IP-адреса), поэтому при постоянном использовании нужна аутентификация.
