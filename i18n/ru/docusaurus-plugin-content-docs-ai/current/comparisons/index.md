# Сравнения

На каждой странице этого раздела StackQL сравнивается с одним другим инструментом или одним архитектурным подходом. Каждое сравнение начинается с честного ответа на вопрос "когда что использовать" и только потом приводит доводы в пользу StackQL.

## Страницы {#pages}

- [StackQL и Terraform: сравнение](/ai/comparisons/stackql-vs-terraform) - движок запросов и изменений в реальном времени в отличие от IaC на основе файла состояния
- [StackQL и Steampipe: сравнение](/ai/comparisons/stackql-vs-steampipe) - облачный SQL для чтения и записи в отличие от облачного SQL только для чтения
- [StackQL и CloudQuery: сравнение](/ai/comparisons/stackql-vs-cloudquery) - запросы в реальном времени в отличие от снимков ELT по расписанию
- [StackQL и собственные MCP-серверы: сравнение](/ai/comparisons/stackql-vs-custom-mcp-servers) - один универсальный интерфейс для агентов в отличие от наборов инструментов, созданных вручную
