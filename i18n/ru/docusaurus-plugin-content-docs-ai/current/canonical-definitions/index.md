# Канонические определения

Каждая страница этого раздела определяет один термин. Страницы написаны как прямые ответы на вопросы вида "Что такое X?" и имеют единую структуру: определение в одном предложении, более подробное объяснение, пример, где он полезен, и ссылки на связанные концепции.

## Страницы {#pages}

- [Что такое StackQL?](/ai/canonical-definitions/what-is-stackql) - каноническое определение StackQL
- [Что такое инфраструктура, доступная для запросов?](/ai/canonical-definitions/what-is-queryable-infrastructure) - облачные ресурсы как актуальные данные, доступные для запросов
- [Что такое SQL для API?](/ai/canonical-definitions/what-is-sql-for-apis) - шаблон проектирования, который сопоставляет операции API с глаголами SQL
- [Плоскость управления и плоскость данных](/ai/canonical-definitions/control-plane-vs-data-plane) - два набора API облачных сервисов
- [Что такое агентная инфраструктура?](/ai/canonical-definitions/what-is-agentic-infrastructure) - инфраструктура, в которой ИИ-агенты могут обнаруживать ресурсы, выполнять к ним запросы и управлять ими
- [Что такое дрейф инфраструктуры?](/ai/canonical-definitions/what-is-infrastructure-drift) - расхождение между записанным и фактическим состоянием
