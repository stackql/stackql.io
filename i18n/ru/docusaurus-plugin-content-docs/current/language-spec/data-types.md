Типы данных StackQL представляют значения входных или выходных полей (свойств или параметров), используемых в облачных ресурсах.  Типы данных StackQL перечислены в таблице ниже:

| Тип StackQL | Описание | Пример |
|--|--|--|
| `string` | последовательность символов Юникода, заключенная в одинарные кавычки | `'mybucket'` |
| `array` | упорядоченная коллекция значений в квадратных скобках `[ ]`, разделенных запятой | `[0,1,2]` |
| `object` | неупорядоченный набор из нуля или более пар "имя/значение", заключенных в `{ }` и разделенных запятой | `{"name": "mydb"}` |
| `boolean` | `true` или `false` без кавычек (значение в кавычках, например `'true'`, обрабатывается как строка) | `true` |
| `integer` | целое число: положительное, отрицательное или ноль | `2` |
| `double` | число с плавающей запятой двойной точности, положительное или отрицательное | `0.95` |
<br/>
<br/>
> Типы данных StackQL соответствуют типам данных, которые используются в API всех основных поставщиков облачных услуг.

## Преобразование типов {#type-conversion}

`CAST(expression AS type)` и `CONVERT(expression, type)` преобразуют значение в другой тип.  Помимо типов преобразования, унаследованных от грамматики MySQL (`CHAR`, `DATE`, `DATETIME`, `DECIMAL`, `SIGNED`, `UNSIGNED`, `TIME`, `JSON`), в StackQL `v1.0` и более поздних версиях принимаются `TEXT`, `INTEGER`, `INT`, `BIGINT`, `BOOLEAN` и `BOOL`.  Преобразование выполняет SQL-бэкенд, поэтому его семантика - это семантика SQLite или PostgreSQL.  Обычно преобразования используются, чтобы сравнить типизированную [переменную сеанса](/getting-started/session-variables) со строковым столбцом:

```sql
SET some_id = 42;

SELECT CAST($some_id AS TEXT) AS id_text,
       CONVERT($some_id, TEXT) || '-east' AS label;
```

Логические поля, которые возвращают провайдеры на основе XML, такие как AWS, выводятся как `true` и `false`; выпуски StackQL до `v1.0` выводили их как `0` и `1`.
