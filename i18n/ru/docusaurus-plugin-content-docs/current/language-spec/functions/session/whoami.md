Возвращает идентификатор субъекта аутентифицированной вызывающей стороны.  Требуется сеанс, при запуске которого включено [управление доступом](/command-line-usage/access-management).  Доступно в StackQL `v1.0` и более поздних версиях.

См. также:  
[[` GROUPS `]](/language-spec/functions/session/groups) [[ Управление доступом ]](/command-line-usage/access-management)

* * * 

## Синтаксис {#syntax}

```sql
SELECT WHOAMI() [ AS <alias> ];
```

## Аргументы {#arguments}

Нет.

## Возвращаемое значение {#return-values}

Возвращает строку с идентификатором субъекта, установленным для текущей инструкции.  В сеансе, запущенном без флага `--access.config`, функция завершается с ошибкой.

* * *

## Примеры {#examples}

### Проверка установленного удостоверения {#inspect-the-established-identity}

Обе функции не принимают аргументов и описывают вызывающую сторону, которую сервер аутентифицировал для этой инструкции.  `whoami()` возвращает идентификатор субъекта, а `groups()` - группы каталога вызывающей стороны, поэтому их совместный запуск позволяет быстро проверить, что токен или сертификат соответствует ожидаемому субъекту, прежде чем выполнять что-либо еще.

```sql
SELECT whoami() AS principal, groups() AS memberships;
```
