Возвращает членство аутентифицированной вызывающей стороны в группах каталога в виде JSON-массива.  Требуется сеанс, при запуске которого включено [управление доступом](/command-line-usage/access-management).  Доступно в StackQL `v1.0` и более поздних версиях.

См. также:  
[[` WHOAMI `]](/language-spec/functions/session/whoami) [[ Управление доступом ]](/command-line-usage/access-management)

* * * 

## Синтаксис {#syntax}

```sql
SELECT GROUPS() [ AS <alias> ];
```

## Аргументы {#arguments}

Нет.

## Возвращаемое значение {#return-values}

Возвращает JSON-массив идентификаторов групп из снимка каталога субъектов, сделанного для текущей инструкции, например `["readers"]`.  Членство обновляется для каждой инструкции, поэтому отзыв членства отражается уже в следующей инструкции.  В сеансе, запущенном без флага `--access.config`, функция завершается с ошибкой.

* * *

## Примеры {#examples}

### Проверка установленного удостоверения {#inspect-the-established-identity}

Вместе эти две функции показывают идентификатор субъекта вызывающей стороны и ее текущие группы каталога.  Так как членство заново считывается для каждой инструкции, выполнение этого запроса после изменения каталога подтверждает, что изменение видно в сеансе.

```sql
SELECT whoami() AS principal, groups() AS memberships;
```
