## Поддерживаемый синтаксис {#supported-syntax}

StackQL поддерживает следующий синтаксис регулярных выражений:    

| Выражение | Описание |
|------------|-------------|
| `X*` | ноль или более вхождений `X` |
| `X+` | одно или более вхождений `X` | 
| `X?` | ноль или одно вхождение `X` |
| `X{n}` | ровно `n` вхождений `X` |
| `X{n,}` | `n` или более вхождений `X` |
| `X{n,m}` | от `n` до `m` вхождений `X` |
| `(X)` | совпадение с `X` |
| `X`&vert;`Y` | `X` или `Y` |
| `^X` | `X` в начале строки |
| `X$` | `X` в конце строки |
| `.` | Совпадение с любым одиночным символом, включая символ новой строки |
| `\c` | Символ `c`, где `c` - один из символов `\{}()[]`&vert;`*+?.` |
| `\c` | Escape-последовательности языка C для `c` из набора `afnrtv`. Например: `\t` или `\n` |
| `[abc]` | Любой одиночный символ из набора `abc` |
| `[^abc]` | Любой одиночный символ, не входящий в набор `abc` |
| `[a-z]` | Любой одиночный символ из диапазона `a-z` |
| `[^a-z]` | Любой одиночный символ вне диапазона `a-z` |
| `\d`, `\w`, `\s` | Цифра, символ слова (`[0-9A-Za-z_]`), пробельный символ |
| `\D`, `\W`, `\S` | Любой символ, кроме цифры, кроме символа слова, кроме пробельного символа |
| `\b` | Граница слова |  

&nbsp;  
&nbsp;  
Шаблоны используют синтаксис RE2 в реализации пакета `regexp` языка Go.  Обратные ссылки (`\1`) и проверки просмотра вперед и назад (lookaround) не поддерживаются: шаблон, в котором они используются, отклоняется с ошибкой.

Обратная косая черта в строковом литерале StackQL начинает escape-последовательность (`'\n'` - это символ новой строки), поэтому обратную косую черту, которая относится к регулярному выражению, записывают дважды: `'\\d+'` соответствует одной или нескольким цифрам, а `'[0-9]+\\.[0-9]+'` - символу точки между цифрами.

Полное описание синтаксиса см. на странице [Синтаксис RE2](https://github.com/google/re2/wiki/Syntax).
