Проверяет, соответствует ли исходная строка заданному шаблону регулярного выражения.

См. также:  
[[`SELECT`]](/language-spec/select)

* * * 

## Синтаксис {#syntax}

```sql
SELECT source_string REGEXP pattern_expression AS match_result FROM <multipartIdentifier>;
```

## Аргументы {#arguments}

__*source_string*__  
Строка, в которой выполняется поиск шаблона.

__*pattern_expression*__  
Шаблон регулярного выражения, с которым сопоставляется исходная строка.

## Возвращаемое значение {#return-values}
Возвращает `1`, если исходная строка соответствует шаблону регулярного выражения, иначе `0`.

* * *

## Примеры {#examples}

### Проверка наличия чисел в строке {#check-if-a-string-contains-numbers}

В этом примере проверяется, содержит ли строка 'the year is 2021' один или несколько цифровых символов:

```sql
SELECT 'the year is 2021' REGEXP '[0-9]+' AS match_result;
```

Этот запрос возвращает `1`, так как строка содержит подстроку '2021', которая соответствует шаблону `[0-9]+`, обозначающему одну или несколько цифр.

### Проверка формата адреса электронной почты {#validate-email-format}

Чтобы проверить, имеет ли строка допустимый формат адреса электронной почты:

```sql
SELECT 'user@example.com' REGEXP '^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\\.[A-Za-z]{2,}$' AS match_result;
```

Этот запрос возвращает `1`: строка 'user@example.com' оформлена как обычный адрес электронной почты и соответствует указанному шаблону регулярного выражения.  Точка перед доменным суффиксом записана как `\\.`, так как строковый литерал StackQL поглощает одну обратную косую черту, и обратную косую черту, которая относится к регулярному выражению, записывают дважды (см. [Справочник по регулярным выражениям](/language-spec/functions/re/reference)).
