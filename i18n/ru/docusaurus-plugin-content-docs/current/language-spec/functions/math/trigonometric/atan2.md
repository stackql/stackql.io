Вычисляет арктангенс двух чисел, а именно угол в радианах, тангенс которого равен отношению двух указанных чисел (y, деленное на x), с правильным учетом знаков входных значений для определения нужной четверти.

См. также:  
[[`SELECT`]](/language-spec/select)

* * * 

## Синтаксис {#syntax}

```sql
SELECT ATAN2(y, x) FROM <multipartIdentifier>;
```

## Аргументы {#arguments}

__*y*__  
Координата y (числитель) точки.

__*x*__  
Координата x (знаменатель) точки.

## Возвращаемое значение {#return-values}
Возвращает арктангенс y/x в радианах с учетом того, в какой четверти лежит угол.

* * *

## Примеры {#examples}

### Вычисление арктангенса для точки (1,1) {#calculate-the-arc-tangent-of-the-point-11}

```sql
SELECT ATAN2(1, 1) AS arc_tangent_value;
```

Этот запрос возвращает π/4, то есть примерно `0.785`, так как арктангенс для точки (1,1) соответствует углу π/4 радиан в первой четверти.

### Вычисление арктангенса для точки (-10, 10) {#calculate-the-arc-tangent-of-the-point--10-10}

```sql
SELECT ATAN2(10, -10) AS arc_tangent_value;
```

Этот запрос вычисляет угол для точки (-10, 10), где y = 10 и x = -10, и возвращает 3π/4, то есть примерно `2.356`: тангенс этого угла равен -1, а точка лежит во второй четверти.
