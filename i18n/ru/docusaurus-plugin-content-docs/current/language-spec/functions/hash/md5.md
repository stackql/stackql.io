Возвращает дайджест MD5 строки в виде 32 шестнадцатеричных символов в нижнем регистре.  Доступно в StackQL `v1.0` и более поздних версиях.

См. также:  
[[` SELECT `]](/language-spec/select) [[ Конкатенация ]](/language-spec/functions/string/concatenation)

* * * 

## Синтаксис {#syntax}

```sql
SELECT MD5(expression) FROM <multipartIdentifier>;
```

## Аргументы {#arguments}

__*expression*__  
Строка или значение, приводимое к тексту.  Для аргумента `NULL` возвращается `NULL`.

## Возвращаемое значение {#return-values}

Возвращает шестнадцатеричную строку из 32 символов в нижнем регистре.

> Функция `MD5` предназначена для получения отпечатков и обнаружения изменений.  Это не примитив для паролей или безопасности.  В бэкенде PostgreSQL используется собственная функция `md5` базы данных.

* * *

## Примеры {#examples}

### Получение отпечатка производного значения {#fingerprint-a-derived-value}

Переменные подставляются как типизированные значения, целое число преобразуется в текст и соединяется с суффиксом, а дайджест вычисляется по результату, приведенному к нижнему регистру.  Одинаковые входные данные всегда дают одну и ту же шестнадцатеричную строку из 32 символов, поэтому значение можно использовать как стабильный ключ.

```sql
SET some_id = 42;
SET suffix = 'East';

SELECT md5(lower(CONVERT($some_id, TEXT) || '-' || $suffix)) AS digest;
```

### Обнаружение изменений конфигурации {#detect-configuration-changes}

Хэширование сериализованного JSON-столбца дает короткое значение, которое можно хранить и сравнивать между запусками.  Если дайджест бакета отличается от дайджеста при предыдущем запуске, конфигурация IAM этого бакета изменилась, и при этом не нужно хранить или сравнивать весь документ.

```sql
SELECT name, md5(json_extract(iamConfiguration, '$')) AS iam_digest
FROM google.storage.buckets
WHERE project = 'stackql-demo';
```
