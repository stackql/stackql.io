Обновляет существующие значения в JSON-объекте по их пути. Функция `JSON_REPLACE` не добавляет в документ новые ключи; она только заменяет значения существующих ключей.

См. также:  
[[`SELECT`]](/language-spec/select) [[` JSON_EXTRACT `]](/language-spec/functions/json/json_extract) [[` JSON_SET `]](/language-spec/functions/json/json_set) [[` JSON_INSERT `]](/language-spec/functions/json/json_insert)

* * * 

## Синтаксис {#syntax}

```sql
SELECT JSON_REPLACE(json_column, path, new_value) FROM <multipartIdentifier>;
```

## Аргументы {#arguments}

__*json_column*__  
JSON-столбец или JSON-выражение, в котором нужно заменить значения.

__*path*__  
Выражение пути JSON, указывающее место в JSON-документе, где нужно выполнить замену. Путь должен указывать на существующий ключ.

__*new_value*__  
Новое значение, которое нужно записать по указанному пути в JSON-документе вместо существующего.

## Возвращаемое значение {#return-values}
Возвращает измененный JSON-документ с замененным значением. Если указанный путь не существует, исходный JSON-документ возвращается без изменений.

:::note Поведение, если ключ существует

| Функция                                                      | Перезаписать, если уже существует? | Создать, если не существует? |
|--------------------------------------------------------------|------------------------------|---------------------------|
| [`json_insert()`](/language-spec/functions/json/json_insert) | Нет                          | Да                        |
| [`json_replace()`](/language-spec/functions/json/json_replace) | Да                           | Нет                       |
| [`json_set()`](/language-spec/functions/json/json_set)       | Да                           | Да                        |

:::

* * *

## Примеры {#examples}

### Замена одного значения в JSON-объекте {#replace-a-single-value-in-a-json-object}

```sql
SELECT sku as original,
JSON_REPLACE(sku, '$.name', 'Standard_EU') as updated
FROM azure.container_registry.registries 
WHERE registry_name = 'exampleRegistryProd' 
AND subscription_id = '12345678-abcd-1234-abcd-1234abcd5678' 
AND resource_group_name = 'exampleResourceGroupProd';
/* expected output...
|---------------------------------------|------------------------------------------|
|               original                |                 updated                  |
|---------------------------------------|------------------------------------------|
| {"name":"Standard","tier":"Standard"} | {"name":"Standard_EU","tier":"Standard"} |
|---------------------------------------|------------------------------------------|
*/
```

```sql
              '$.ipConfigurations[0].type',

              '$.ipConfigurations[0].properties.privateIPAllocationMethod',
              '$.ipConfigurations[0].properties.primary',
              '$.ipConfigurations[0].properties.privateIPAddressVersion'
            ),
  '$.ipConfigurations[0].name',
  'vmss-flex-vnet-nic01-defaultIpConfiguration'
  ) afterchange
from
  azure.network.network_interfaces
where subscription_id = '0123456789'
and resource_group_name = 'vm-rg'
and network_interface_name = 'vm1450_z1'
```
