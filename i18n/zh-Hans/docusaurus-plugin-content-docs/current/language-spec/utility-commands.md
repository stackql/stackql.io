StackQL 实用命令如下表所示：

| 实用命令 | 说明 | 示例 |
|--|--|--|
| `clear` | 清除 shell 中的结果和命令，不需要以分号结尾 | `clear` 或 `CLEAR` |
| `sleep n` | 休眠 `n` 毫秒  | `sleep 5000` 或 `SLEEP 5000` |
