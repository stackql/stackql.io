StackQL のユーティリティコマンドを次の表に示します。

| ユーティリティコマンド | 説明 | 例 |
|--|--|--|
| `clear` | シェルから結果とコマンドを消去する（セミコロンで終える必要はない） | `clear` または `CLEAR` |
| `sleep n` | `n` ミリ秒間スリープする  | `sleep 5000` または `SLEEP 5000` |
