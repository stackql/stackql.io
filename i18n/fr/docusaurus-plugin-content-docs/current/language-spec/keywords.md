Les mots-clés sont des mots réservés qui ont une signification dans la grammaire StackQL.  Ils peuvent être saisis dans n'importe quelle casse (majuscules, minuscules ou mixte) ; par convention, ils sont écrits en majuscules dans tous les exemples.  Les mots-clés de StackQL sont notamment :

`ADD`, `AND`, `AS`, `ASC`, `BETWEEN`, `BINARY`, `BY`, `CASE`, `COLLATE`, `CONVERT`, `CREATE`, `CROSS`, `CURRENT_DATE`, `CURRENT_TIME`, `CURRENT_TIMESTAMP`, `DATABASE`, `DATABASES`, `DELETE`, `DESC`, `DESCRIBE`, `DISTINCT`, `DIV`, `DROP`, `ELSE`, `END`, `ESCAPE`, `EXEC`, `EXISTS`, `EXPLAIN`, `FALSE`, `FOR`, `FROM`, `GROUP`, `HAVING`, `IF`, `IGNORE`, `IN`, `INDEX`, `INNER`, `INSERT`, `INTERVAL`, `INTO`, `IS`, `JOIN`, `LEFT`, `LIKE`, `LIMIT`, `LOCALTIME`, `LOCALTIMESTAMP`, `LOCK`, `MOD`, `NATURAL`, `NEXT`, `NOT`, `NULL`, `OFF`, `ON`, `OR`, `ORDER`, `OUTER`, `OVER`, `RECURSIVE`, `REGEXP`, `REPLACE`, `RETURNING`, `RIGHT`, `SCHEMA`, `SELECT`, `SEPARATOR`, `SESSION`, `SET`, `SHOW`, `SUBSTR`, `SUBSTRING`, `TABLE`, `THEN`, `TIMESTAMPADD`, `TIMESTAMPDIFF`, `TO`, `TRUE`, `UNION`, `UNSET`, `UPDATE`, `USE`, `USING`, `UTC_DATE`, `UTC_TIME`, `UTC_TIMESTAMP`, `VALUES`, `WHEN`, `WHERE`, `XOR`
