Les commandes utilitaires de StackQL sont listées dans le tableau ci-dessous :

| Commande utilitaire | Description | Exemple |
|--|--|--|
| `clear` | Efface les résultats et les commandes du shell, n'a pas besoin d'être terminée par un point-virgule | `clear` ou `CLEAR` |
| `sleep n` | Met en pause pendant `n` millisecondes  | `sleep 5000` ou `SLEEP 5000` |
