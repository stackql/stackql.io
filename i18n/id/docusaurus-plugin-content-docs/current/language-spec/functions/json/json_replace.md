Memperbarui nilai yang sudah ada dalam objek JSON berdasarkan jalurnya. `JSON_REPLACE` tidak menambahkan kunci baru ke dokumen; fungsi ini hanya mengganti nilai dari kunci yang sudah ada.

Lihat juga:  
[[`SELECT`]](/language-spec/select) [[` JSON_EXTRACT `]](/language-spec/functions/json/json_extract) [[` JSON_SET `]](/language-spec/functions/json/json_set) [[` JSON_REPLACE `]](/language-spec/functions/json/json_replace)

* * * 

## Sintaksis {#syntax}

```sql
SELECT JSON_REPLACE(json_column, path, new_value) FROM <multipartIdentifier>;
```

## Argumen {#arguments}

__*json_column*__  
Kolom atau ekspresi JSON yang nilainya akan diganti.

__*path*__  
Ekspresi jalur JSON yang menunjuk ke lokasi di dalam dokumen JSON tempat penggantian dilakukan. Jalur harus menunjuk ke kunci yang sudah ada.

__*new_value*__  
Nilai baru yang akan menggantikan nilai pada jalur yang ditentukan dalam dokumen JSON.

## Nilai yang dikembalikan {#return-values}
Mengembalikan dokumen JSON yang telah dimodifikasi, dengan nilai yang ditentukan sudah diganti. Jika jalur yang ditentukan tidak ada, dokumen JSON asli dikembalikan tanpa perubahan.

:::note Perilaku jika kunci sudah ada

| Fungsi                                                       | Timpa jika sudah ada?        | Buat jika belum ada?      |
|--------------------------------------------------------------|------------------------------|---------------------------|
| [`json_insert()`](/language-spec/functions/json/json_insert) | Tidak                        | Ya                        |
| [`json_replace()`](/language-spec/functions/json/json_replace) | Ya                           | Tidak                     |
| [`json_set()`](/language-spec/functions/json/json_set)       | Ya                           | Ya                        |

:::

* * *

## Contoh {#examples}

### Mengganti satu nilai dalam objek JSON {#replace-a-single-value-in-a-json-object}

```sql
SELECT sku as original,
JSON_REPLACE(sku, '$.name', 'Standard_EU') as updated
FROM azure.container_registry.registries 
WHERE registry_name = 'exampleRegistryProd' 
AND subscription_id = '12345678-abcd-1234-abcd-1234abcd5678' 
AND resource_group_name = 'exampleResourceGroupProd';
/* expected output...
|---------------------------------------|------------------------------------------|
|               original                |                 updated                  |
|---------------------------------------|------------------------------------------|
| {"name":"Standard","tier":"Standard"} | {"name":"Standard_EU","tier":"Standard"} |
|---------------------------------------|------------------------------------------|
*/
```

```sql
select
  properties beforechange,
  json_replace(json_remove(properties,
              '$.allowPort25Out',
              '$.auxiliarySku',
              '$.provisioningState',
              '$.resourceGuid',
              '$.macAddress',
              '$.vnetEncryptionSupported',
              '$.enableIPForwarding',
              '$.defaultOutboundAccess',
              '$.primary',
              '$.virtualMachine',
              '$.hostedWorkloads',
              '$.tapConfigurations',
              '$.nicType',
              '$.auxiliaryMode',
              '$.ipConfigurations[0].id',
              '$.ipConfigurations[0].etag',
              '$.ipConfigurations[0].type',
              '$.ipConfigurations[0].properties.provisioningState',
              '$.ipConfigurations[0].properties.privateIPAddress',
              '$.ipConfigurations[0].properties.privateIPAllocationMethod',
              '$.ipConfigurations[0].properties.primary',
              '$.ipConfigurations[0].properties.privateIPAddressVersion'
            ),
  '$.ipConfigurations[0].name',
  'vmss-flex-vnet-nic01-defaultIpConfiguration'
  ) afterchange
from
  azure.network.network_interfaces
where subscription_id = '0123456789'
and resource_group_name = 'vm-rg'
and network_interface_name = 'vm1450_z1'
```
