```sql
INSERT [ /*+ AWAIT  */ ] [ IGNORE ] [ INTO ] <multipartIdentifier>
( field_name [, field_name] ... )
{ VALUES ( value [, value] ... ) | <selectExpression> }
[ RETURNING field_name [, field_name] ... ];
```

* * *

## Klausa `RETURNING` {#returning-clause}

Klausa `RETURNING` memungkinkan Anda mengambil data dari respons operasi `INSERT`. Hal ini sangat berguna ketika:
- API mengembalikan informasi penting seperti ID yang dihasilkan, kode status, atau metadata lainnya
- Anda perlu menangkap data respons untuk pemrosesan lebih lanjut
- Anda ingin memverifikasi hasil operasi

Field yang ditentukan dalam klausa `RETURNING` akan dideserialisasi dari respons API dan ditampilkan dalam kumpulan hasil.

* * *

## Contoh {#examples}

### Pernyataan `INSERT` dasar {#basic-insert-statement}
Jalankan pernyataan `INSERT` untuk membuat sumber daya Compute Engine Disk.  Ini adalah pemanggilan yang tidak memblokir (asinkron).

```sql
-- Create a Compute Engine Disk resource
INSERT INTO google.compute.disks (project, zone, name, sizeGb) 
SELECT 'stackql-demo', 
'australia-southeast1-a', 
'test10gbdisk', 10;
```

### Pernyataan `INSERT` (memblokir) {#insert-statement-blocking}
Jalankan pernyataan `INSERT` untuk membuat sumber daya Compute Engine Disk.  Ini adalah pemanggilan yang memblokir (sinkron).

```sql
-- Create a Compute Engine Disk resource
INSERT /*+ AWAIT  */ INTO google.compute.disks (project, zone, name, sizeGb) 
SELECT 'stackql-demo', 
'australia-southeast1-a', 
'test10gbdisk', 10;
```

### Pernyataan `INSERT` dengan `SELECT` {#insert-statement-with-select}
Jalankan pernyataan `INSERT` dengan `SELECT`.

```sql
-- Create an Azure Network Interface
INSERT INTO azure.network.network_interfaces
  (
    resource_group_name,
    subscription_id,
    network_interface_name,
    data__location,
    data__properties
  )
  SELECT
    'vmss-flex',
    '0123456789',
    'vmss-flex-vnet-nic01-manual-' || '1',
    'eastus',
    json_replace(json_remove(properties,
                                  '$.allowPort25Out',
                                  '$.auxiliarySku',
                                  '$.provisioningState',
                                  '$.resourceGuid',
                                  '$.macAddress',
                                  '$.vnetEncryptionSupported',
                                  '$.enableIPForwarding',
                                  '$.defaultOutboundAccess',
                                  '$.primary',
                                  '$.virtualMachine',
                                  '$.hostedWorkloads',
                                  '$.tapConfigurations',
                                  '$.nicType',
                                  '$.auxiliaryMode',
                                  '$.ipConfigurations[0].id',
                                  '$.ipConfigurations[0].etag',
                                  '$.ipConfigurations[0].type',
                                  '$.ipConfigurations[0].properties.provisioningState',
                                  '$.ipConfigurations[0].properties.privateIPAddress',
                                  '$.ipConfigurations[0].properties.privateIPAllocationMethod',
                                  '$.ipConfigurations[0].properties.primary',
                                  '$.ipConfigurations[0].properties.privateIPAddressVersion'
                                ),
                      '$.ipConfigurations[0].name',
                      'vmss-flex-vnet-nic01-defaultIpConfiguration'
                      )
  FROM
    azure.network.network_interfaces
  WHERE subscription_id = '0123456789'
  AND resource_group_name = 'vmss-flex'
  AND network_interface_name = 'vmss-nic-01';
```

### Pernyataan `INSERT` dengan klausa `RETURNING` {#insert-statement-with-returning-clause}
Jalankan pernyataan `INSERT` dan ambil field tertentu dari respons API.

```sql
-- Execute a Snowflake SQL statement and return the response data
INSERT INTO snowflake.sqlapi.statements (
    data__statement,
    data__timeout,
    data__database,
    data__schema,
    "User-Agent",
    endpoint
)
SELECT
    'SELECT
        customer_id,
        customer_name,
        email,
        credit_card_number,
        purchase_amount,
        purchase_date
    FROM CUSTOMER_DATA',
    10,
    'MY_DATABASE',
    'MY_SCHEMA',
    'User-Agent',
    'ABCDEF-XY12345'
RETURNING code, sqlState, message, data;
```

|        |          |                                | Smith","john.smith@example.com","***MASKED***","199.99","20263"]]           |
