Повертає дайджест MD5 рядка у вигляді 32 шістнадцяткових символів у нижньому регістрі.  Доступно в StackQL `v1.0` і новіших версіях.

Див. також:  
[[` SELECT `]](/language-spec/select) [[ Конкатенація ]](/language-spec/functions/string/concatenation)

* * * 

## Синтаксис {#syntax}

```sql
SELECT MD5(expression) FROM <multipartIdentifier>;
```

## Аргументи {#arguments}

__*expression*__  
Рядок або значення, приведене до тексту.  Для аргументу `NULL` функція повертає `NULL`.

## Значення, що повертається {#return-values}

Повертає рядок із 32 шістнадцяткових символів у нижньому регістрі.

> Функція `MD5` призначена для створення відбитків і виявлення змін.  Вона не є примітивом для паролів чи безпеки.  На бекенді PostgreSQL використовується власна функція `md5` бази даних.

## Приклади {#examples}

### Створення відбитка похідного значення {#fingerprint-a-derived-value}

Змінні підставляються як типізовані значення, ціле число перетворюється на текст і приєднується до суфікса, а дайджест обчислюється від результату, переведеного в нижній регістр.  Однакові вхідні дані завжди дають той самий шістнадцятковий рядок із 32 символів, тому це значення можна використовувати як стабільний ключ.

```sql
SET some_id = 42;
SET suffix = 'East';

SELECT md5(lower(CONVERT($some_id, TEXT) || '-' || $suffix)) AS digest;
```

### Виявлення змін конфігурації {#detect-configuration-changes}

Хешування серіалізованого стовпця JSON дає коротке значення, яке можна зберігати й порівнювати між запусками.  Якщо дайджест бакета відрізняється від попереднього запуску, його конфігурацію IAM змінено, і для цього не потрібно зберігати чи порівнювати весь документ.

```sql
SELECT name, md5(json_extract(iamConfiguration, '$')) AS iam_digest
FROM google.storage.buckets
WHERE project = 'stackql-demo';
```
