## Підтримуваний синтаксис {#supported-syntax}

StackQL підтримує такий синтаксис регулярних виразів:    

| Вираз | Опис |
|------------|-------------|
| `X*` | нуль або більше входжень `X` |
| `X+` | одне або більше входжень `X` | 
| `X?` | нуль або одне входження `X` |
| `X{n}` | рівно `n` входжень `X` |
| `X{n,}` | `n` або більше входжень `X` |
| `X{n,m}` | від `n` до `m` входжень `X` |
| `(X)` | збіг із `X` |
| `X`&vert;`Y` | `X` або `Y` |
| `^X` | `X` на початку рядка |
| `X$` | `X` у кінці рядка |
| `.` | Збіг із будь-яким одним символом, зокрема із символом нового рядка |
| `\c` | Символ `c`, де `c` - один із символів `\{}()[]`&vert;`*+?.` |
| `\c` | Escape-послідовності мови C для `c` з набору `afnrtv`. Напр.: `\t` або `\n` |
| `[abc]` | Будь-який один символ із набору `abc` |
| `[^abc]` | Будь-який один символ, якого немає в наборі `abc` |
| `[a-z]` | Будь-який один символ із діапазону `a-z` |
| `[^a-z]` | Будь-який один символ поза діапазоном `a-z` |
| `\d`, `\w`, `\s` | Цифра, символ слова (`[0-9A-Za-z_]`), пробільний символ |
| `\D`, `\W`, `\S` | Будь-який символ, що не є цифрою, не є символом слова, не є пробільним символом |
| `\b` | Межа слова |  

&nbsp;  
&nbsp;  
Шаблони використовують синтаксис RE2 у реалізації пакета `regexp` мови Go.  Зворотні посилання (`\1`) і випереджальні та ретроспективні перевірки (lookaround) не підтримуються: шаблон, який їх використовує, відхиляється з помилкою.

Зворотна скісна риска в рядковому літералі StackQL починає escape-послідовність (`'\n'` - це символ нового рядка), тому зворотну скісну риску, що належить до регулярного виразу, записують двічі: `'\\d+'` відповідає одній або більше цифрам, а `'[0-9]+\\.[0-9]+'` - символу крапки між цифрами.

Повний опис синтаксису див. на сторінці [Синтаксис RE2](https://github.com/google/re2/wiki/Syntax).
