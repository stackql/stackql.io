Обчислює арктангенс двох чисел, а саме кут у радіанах, тангенс якого дорівнює відношенню двох вказаних чисел (y, поділене на x), з правильним урахуванням знаків вхідних значень для визначення правильної чверті.

Див. також:  
[[`SELECT`]](/language-spec/select)

* * * 

## Синтаксис {#syntax}

```sql
SELECT ATAN2(y, x) FROM <multipartIdentifier>;
```

## Аргументи {#arguments}

__*y*__  
Координата y (чисельник) точки.

__*x*__  
Координата x (знаменник) точки.

## Значення, що повертається {#return-values}
Повертає арктангенс y/x у радіанах з урахуванням правильної чверті кута.

* * *

## Приклади {#examples}

### Обчислення арктангенса для точки (1,1) {#calculate-the-arc-tangent-of-the-point-11}

```sql
SELECT ATAN2(1, 1) AS arc_tangent_value;
```

Цей запит повертає π/4, або приблизно `0.785`, оскільки арктангенс для точки (1,1) відповідає куту π/4 радіана в першій чверті.

### Обчислення арктангенса для точки (-10, 10) {#calculate-the-arc-tangent-of-the-point--10-10}

```sql
SELECT ATAN2(10, -10) AS arc_tangent_value;
```

Цей запит обчислює кут точки (-10, 10), де y = 10 і x = -10, і повертає 3π/4, або приблизно `2.356`: тангенс цього кута дорівнює -1, а точка лежить у другій чверті.
