Типи даних StackQL описують значення вхідних або вихідних полів (властивостей або параметрів) хмарних ресурсів.  Типи даних StackQL наведено в таблиці нижче:

| Тип StackQL | Опис | Приклад |
|--|--|--|
| `string` | послідовність символів Unicode в одинарних лапках | `'mybucket'` |
| `array` | упорядкована колекція значень у квадратних дужках `[ ]`, розділених комою | `[0,1,2]` |
| `object` | невпорядкована множина з нуля або більше пар "ім'я/значення" між `{ }`, розділених комою | `{"name": "mydb"}` |
| `boolean` | `true` або `false` без лапок (значення в лапках, наприклад `'true'`, обробляється як рядкове значення) | `true` |
| `integer` | ціле число, яке може бути додатним, від'ємним або нулем | `2` |
| `double` | число з рухомою комою подвійної точності, може бути додатним або від'ємним | `0.95` |
<br/>
<br/>
> Типи даних StackQL відповідають типам даних, які надають API всіх основних постачальників хмарних послуг.

## Перетворення типів {#type-conversion}

`CAST(expression AS type)` і `CONVERT(expression, type)` перетворюють значення на інший тип.  Окрім типів перетворення, успадкованих із граматики MySQL (`CHAR`, `DATE`, `DATETIME`, `DECIMAL`, `SIGNED`, `UNSIGNED`, `TIME`, `JSON`), StackQL `v1.0` і новіші версії приймають `TEXT`, `INTEGER`, `INT`, `BIGINT`, `BOOLEAN` і `BOOL`.  Перетворення виконує бекенд SQL, тому його семантика відповідає семантиці SQLite або PostgreSQL.  Перетворення зазвичай використовують, щоб порівняти типізовану [змінну сеансу](/getting-started/session-variables) з рядковим стовпцем:

```sql
SET some_id = 42;

SELECT CAST($some_id AS TEXT) AS id_text,
       CONVERT($some_id, TEXT) || '-east' AS label;
```

Логічні поля, які надають провайдери на основі XML, як-от AWS, повертаються як `true` і `false`; випуски StackQL до `v1.0` повертали їх як `0` і `1`.
