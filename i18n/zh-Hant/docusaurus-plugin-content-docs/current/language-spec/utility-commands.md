下表列出 StackQL 公用程式命令：

| 公用程式命令 | 描述 | 範例 |
|--|--|--|
| `clear` | 清除 shell 中的結果與命令，不需要以分號結尾 | `clear` 或 `CLEAR` |
| `sleep n` | 休眠 `n` 毫秒 | `sleep 5000` 或 `SLEEP 5000` |
