StackQL gives AI agents a SQL interface to query and manage cloud and SaaS resources through the Model Context Protocol (MCP).

- [MCP Server](/command-line-usage/mcp) - run and configure the StackQL MCP server.
- [MCP Tools](/mcp) - discover providers, inspect resources and execute SQL through MCP tools.
- [Embedded MCP](/mcp/embedded) - embed the MCP server in your application.
- [Query Library](pathname:///docs/query-library/) - explore reusable SQL queries.
- [AI Reference](/ai) - browse concepts, how-tos, comparisons and troubleshooting.
